# Sponsor Disclosure — Template de Divulgação

## ⚠️ REGRA FUNDAMENTAL

**Toda publicidade DEVE ser claramente identificada como tal.**

Não fazer isso é:
- Violação do Código de Defesa do Consumidor (CDC)
- Violação do Código de Autorregulamentação Publicitária (CONAR)
- Propaganda enganosa (passível de processo)
- Perda de confiança da audiência

**Quando em dúvida: seja transparente.**

---

## Base Legal

### CONAR (Código de Autorregulamentação Publicitária)
- **Art. 28:** Publicidade deve ser distinguível da programação editorial
- **Art. 29:** Proibição de publicidade clandestina ou subliminar
- **Art. 30:** Identificação clara de anúncios pagos

### CDC (Código de Defesa do Consumidor)
- **Art. 36:** Publicidade deve ser identificável como tal
- **Art. 37:** Proibição de publicidade enganosa ou abusiva

## Formatos de Disclosure

### 1. Áudio (Falado pelo Host)

**OBRIGATÓRIO:** Disclosure ANTES do ad-read.

#### Template Básico
```
"Este episódio é patrocinado por [Marca]."
```

#### Template com Contexto
```
"Antes de continuar, quero agradecer ao patrocinador deste episódio, [Marca], que torna possível a produção deste conteúdo."
```

#### Template para Midroll
```
"Este episódio conta com o apoio de [Marca]."
```

#### Template para Host-Read Integrado
```
"Este é um momento patrocinado. [Ad-read integrado]. Novamente, obrigado a [Marca] por tornar este episódio possível."
```

**NUNCA:**
- Disfarçar publicidade como recomendação pessoal sem disclosure
- Dizer "Este produto é incrível" sem avisar que é patrocinado

**SEMPRE:**
- Disclosure no início do ad-read
- Disclosure MESMO se você genuinamente gosta do produto

---

### 2. Show Notes (Descrição do Episódio)

#### Template Início dos Show Notes
```
[Patrocinado] Este episódio conta com o apoio de [Marca].
```

#### Template Seção de Patrocínio
```
## Patrocinadores

Este episódio é apresentado por:
- [Marca 1]: [Descrição curta] — [Link com disclosure]
- [Marca 2]: [Descrição curta] — [Link com disclosure]
```

#### Template para Links
```
[Marca] (Link de afiliado — podemos receber comissão)
```

---

### 3. Redes Sociais

#### Instagram/TikTok/YouTube
**Obrigatório:** Disclosure visível SEM precisar clicar em "ver mais".

```
#publi [Marca] — Parceria comercial
```

ou

```
Parceria com [Marca] #ad
```

ou

```
Conteúdo patrocinado por [Marca]
```

**Onde colocar:**
- Primeiras 2 linhas da caption (antes do "ver mais")
- OU overlay de texto no vídeo (primeiro frame)

#### Twitter/X
```
[Conteúdo] — Parceria com [Marca] #ad
```

#### LinkedIn
```
Disclosure: Este post é uma parceria comercial com [Marca].
```

---

### 4. Affiliate Links (Links de Afiliado)

**SEMPRE avisar que é link de afiliado.**

#### Show Notes
```
Conheça [Produto] em [link]
(Link de afiliado — podemos receber uma comissão se você comprar através deste link, sem custo adicional para você)
```

#### Versão Curta
```
[Produto] — [link de afiliado] (link afiliado)
```

#### Redes Sociais
```
Link de afiliado na bio — podemos receber comissão
```

---

### 5. Gifted Products (Produtos Enviados de Graça)

**Disclosure obrigatório mesmo se não for pago.**

#### Template
```
"Produto enviado por [Marca] para avaliação. Todas as opiniões são minhas."
```

ou

```
"[Marca] enviou este produto de cortesia. Minha análise é honesta e independente."
```

**NUNCA:**
- Falar de produto enviado sem avisar
- Dizer que comprou quando recebeu de graça

---

### 6. Bartering (Troca de Serviços)

Se você recebeu algo em troca (hospedagem grátis, acesso VIP, curso gratuito):

```
"[Marca] forneceu [serviço/produto] em troca de menção neste episódio."
```

## Frequência de Disclosure

### Episódio Completo
- **Início:** Disclosure falado
- **Durante o ad-read:** Contextualizar novamente se ad-read for longo
- **Show notes:** Disclosure escrito

### Clips de Redes Sociais
- **SEMPRE:** Disclosure no clip, mesmo se o episódio completo já tiver
- **Não vale:** "Disclosure no episódio completo" — cada peça de conteúdo precisa do próprio disclosure

---

## Casos Especiais

### 1. Uso Pessoal vs. Patrocínio
**Cenário:** Você usa o produto pessoalmente E ele patrocina.

```
"Eu já usava [Produto] antes deles patrocinarem este episódio, e agora eles são nossos parceiros oficiais."
```

### 2. Opinião Divergente
**Cenário:** Patrocinador enviou produto mas você não gostou.

**Opção A:** Não fazer o ad-read (devolver produto/dinheiro)
**Opção B:** Ser honesto
```
"Este episódio é patrocinado por [Marca]. Testei o produto e aqui está minha opinião honesta: [opinião]."
```

### 3. Patrocínio de Temporada
```
"Esta temporada é apresentada por [Marca]."
```

Repetir disclosure em cada episódio da temporada.

### 4. Eventos Patrocinados
```
"Estou aqui no [Evento] como convidado de [Marca]. Todas as despesas foram cobertas por eles."
```

## Checklist de Compliance

Antes de publicar episódio patrocinado:

- [ ] Disclosure falado ANTES do ad-read?
- [ ] Disclosure nos show notes?
- [ ] Links de afiliado identificados?
- [ ] Clips de redes sociais com disclosure?
- [ ] Hashtags #publi ou #ad usadas?
- [ ] Gifted products declarados?
- [ ] Disclosure está VISÍVEL (não escondido em "ver mais")?

---

## Red Flags — O Que NUNCA Fazer

❌ **Publicidade disfarçada de conteúdo**
```
"Hoje vamos falar de [produto incrível]" — sem avisar que é pago
```

❌ **Disclosure escondido**
```
[500 palavras de texto] ... #ad (no final que ninguém lê)
```

❌ **Disclosure ambíguo**
```
"Obrigado a [Marca]" — não fica claro se é parceria comercial
```

❌ **Omitir affiliate**
```
"Use meu link" — sem avisar que ganha comissão
```

❌ **Fingir que comprou**
```
"Comprei [produto]" — quando recebeu de graça
```

## Templates Prontos

### Intro Padrão (Único Patrocinador)
```
"Antes de começar, este episódio é apresentado por [Marca]. [Ad-read]. Obrigado a [Marca] por tornar este conteúdo possível."
```

### Intro Padrão (Múltiplos Patrocinadores)
```
"Este episódio conta com o apoio de [Marca 1], [Marca 2] e [Marca 3]. Vou falar sobre eles ao longo do episódio."
```

### Midroll
```
"Vamos fazer uma pausa para falar sobre [Marca], patrocinador deste episódio. [Ad-read]."
```

### Postroll
```
"Para encerrar, obrigado a [Marca] por patrocinar este episódio. [Ad-read]."
```

### Show Notes
```
---
PATROCINADORES

Este episódio é apresentado por:

[Marca]: [Descrição]. Use o código [CÓDIGO] para [desconto].
Link: [URL] (link de afiliado)

---
```
