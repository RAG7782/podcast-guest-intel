# Checklist: Pre-Publicacao

**Quando usar:** Antes de publicar QUALQUER episodio

**Owner:** @distributor + @editor + @guardian

## Audio Final

- [ ] Master aprovado por @engineer
- [ ] LUFS verificado por plataforma:
  - [ ] Spotify: -14 LUFS
  - [ ] Apple Podcasts: -16 LUFS
  - [ ] YouTube: -14 LUFS
  - [ ] Amazon Music: -14 LUFS
- [ ] True Peak: max -1 dB (nenhuma plataforma trunca)
- [ ] Listening test feito em 3+ devices:
  - [ ] Fones (qualidade)
  - [ ] Speaker de celular (inteligibilidade)
  - [ ] Car audio (ambiente ruidoso)
- [ ] Formatos exportados:
  - [ ] WAV (arquivo master, backup)
  - [ ] MP3 320kbps (para hosting/RSS)
  - [ ] AAC (para YouTube, se aplicavel)
- [ ] Arquivo final nomeado corretamente: `S{XX}E{XX}_{titulo}_MASTER.wav`

## Metadata

- [ ] Titulo do episodio:
  - [ ] Max 60 caracteres (visibilidade em mobile)
  - [ ] Keyword principal no inicio (SEO)
  - [ ] Claro e atrativo (nao generico)
- [ ] Descricao:
  - [ ] Primeiras 150 caracteres sao hook (aparecem em preview)
  - [ ] Inclui keywords naturalmente
  - [ ] CTA claro (subscribe, review, visite site)
  - [ ] Links funcionais (website, social, guest links)
- [ ] Tags/Keywords:
  - [ ] 5-10 tags relevantes
  - [ ] Mix de broad e niche (ex: "marketing" + "podcasting para B2B")
- [ ] Category:
  - [ ] Primary category correta (ex: Business, Technology, Education)
  - [ ] Secondary category (se plataforma permite)
- [ ] Episode number: S{XX}E{XX} (consistente em todas as plataformas)
- [ ] Publish date e hora agendados (ideal: mesmo dia/hora toda semana)

## Content

- [ ] Show notes publicadas no site:
  - [ ] 2000+ palavras (SEO-friendly)
  - [ ] Timestamps clicaveis (ex: 05:23 - Topico X)
  - [ ] H1 com keyword principal
  - [ ] H2 por secao/topico
  - [ ] Links internos (episodios relacionados)
  - [ ] Links externos (fontes, guest bio)
  - [ ] CTA no final (subscribe, review, membership)
- [ ] SEO page indexavel:
  - [ ] URL amigavel: `/podcast/S01E05-titulo-episodio/`
  - [ ] Meta title (50-60 chars)
  - [ ] Meta description (150-160 chars)
  - [ ] Open Graph tags (preview em social)
  - [ ] Schema markup: PodcastEpisode (structured data)
- [ ] Chapters inseridos (se plataforma suporta):
  - [ ] Capitulos no arquivo MP3 (ID3 tags)
  - [ ] Ou usando Podcasting 2.0 (chapters tag no RSS)
- [ ] Transcript publicado:
  - [ ] Editado (nao apenas auto-generated)
  - [ ] Formatado para leitura (paragrafos, pontuacao)
  - [ ] Acessivel (screen reader friendly)
  - [ ] Publicado na pagina do episodio (bom para SEO)

## Visual Assets

- [ ] Artwork por plataforma:
  - [ ] 3000x3000px (Apple Podcasts, Spotify)
  - [ ] 1400x1400px (fallback)
  - [ ] Formato: JPG ou PNG, max 500KB
  - [ ] Legivel mesmo em tamanho pequeno (teste em mobile)
  - [ ] Inclui: titulo do episodio, numero, guest name (se aplicavel)
- [ ] Thumbnail YouTube (se video):
  - [ ] 1280x720px (16:9)
  - [ ] High contrast, texto grande
  - [ ] Face do host/guest visivel (CTR maior)
  - [ ] A/B test (criar 2-3 opcoes, escolher melhor)
- [ ] Social assets:
  - [ ] Instagram post: 1080x1080px (quadrado)
  - [ ] Instagram Story: 1080x1920px (vertical)
  - [ ] Twitter/X: 1200x675px (horizontal)
  - [ ] LinkedIn: 1200x627px
  - [ ] Audiogram: video curto com waveform (30-60s)

## Social Media

- [ ] Clips prontos para publicacao:
  - [ ] 3-5 clips editados (TikTok, Reels, Shorts)
  - [ ] Legendas adicionadas (auto + manual review)
  - [ ] Hook nos primeiros 3 segundos
  - [ ] Formato vertical (9:16) e quadrado (1:1)
- [ ] Copies escritos por canal:
  - [ ] Instagram: hook + context + hashtags + CTA
  - [ ] Twitter/X: quote + link + thread (opcional)
  - [ ] LinkedIn: contexto profissional + insight + link
  - [ ] TikTok: hook curto + emoji + "link na bio"
  - [ ] YouTube: keyword-rich description + timestamps
- [ ] Posts agendados:
  - [ ] Dia do lancamento: post principal (todas as plataformas)
  - [ ] Dia +1: clips (TikTok, Reels, Shorts)
  - [ ] Dia +2: behind the scenes
  - [ ] Dia +3: quote cards
- [ ] Newsletter draft pronta:
  - [ ] Subject line com hook
  - [ ] Resumo do episodio (3-5 paragrafos)
  - [ ] Key takeaways (3-5 bullets)
  - [ ] CTA para ouvir episodio
  - [ ] Preview do proximo episodio

## Compliance & Ethics

- [ ] Fact-check aprovado por @guardian:
  - [ ] Claims principais verificados
  - [ ] Fontes checadas
  - [ ] Nenhuma desinformacao detectada
- [ ] Disclosures inseridos:
  - [ ] Sponsor mentions (se aplicavel): "Este episodio e patrocinado por..."
  - [ ] Affiliate links: "Este link e um link de afiliado"
  - [ ] Conflicts of interest: "Nota: eu invisto nesta empresa"
- [ ] LGPD/Privacy:
  - [ ] Nenhum dado sensivel exposto sem consentimento
  - [ ] Guest autorizou uso da voz/imagem (termo assinado)
  - [ ] Nenhum menor de idade sem autorizacao dos pais
- [ ] Diversity check:
  - [ ] Se guest: atualizar diversity-check da temporada
  - [ ] Confirmar: estamos atingindo meta de diversidade?
- [ ] Content warnings (se aplicavel):
  - [ ] Linguagem explicita
  - [ ] Topicos sensiveis (violencia, saude mental, etc)
  - [ ] Avisar no inicio do episodio + show notes

## Transcript & Accessibility

- [ ] Transcript completo:
  - [ ] Auto-generated + manual review
  - [ ] Formatado (Speaker 1, Speaker 2, paragrafos)
  - [ ] Corrigido (sem erros obvios de transcricao)
  - [ ] Publicado na pagina do episodio
- [ ] Accessibility:
  - [ ] Alt text em todas as imagens
  - [ ] Closed captions em videos (YouTube)
  - [ ] Screen reader friendly (heading structure)

## Backup & Archival

- [ ] Arquivos originais salvos em 3 locais:
  - [ ] Local 1: HD externo
  - [ ] Local 2: Cloud storage (Google Drive, Dropbox)
  - [ ] Local 3: Backup offsite (Backblaze, S3)
- [ ] Estrutura de pastas:
  - `/audio/S{XX}/E{XX}/raw/` - Audio raw da gravacao
  - `/audio/S{XX}/E{XX}/edited/` - Audio editado (pre-master)
  - `/audio/S{XX}/E{XX}/master/` - Audio final (por plataforma)
  - `/video/S{XX}/E{XX}/raw/` - Video raw (se aplicavel)
  - `/video/S{XX}/E{XX}/final/` - Video final
  - `/assets/S{XX}/E{XX}/` - Artwork, thumbnails, social assets
- [ ] Metadata sheet atualizado (spreadsheet com info de todos os episodios):
  - Episode number, titulo, guest, data de gravacao, data de publicacao, links, metrics

## Final Check (30 min antes de publish)

- [ ] Ouvir episodio completo UMA ULTIMA VEZ (host ou producer)
- [ ] Verificar: nenhum erro de edicao (cortes estranhos, vinheta no lugar errado)
- [ ] Verificar: audio quality impecavel (sem ruido, levels ok)
- [ ] Verificar: links nas show notes funcionam
- [ ] Verificar: artwork correta (nome do guest correto, sem typos)
- [ ] Verificar: posts sociais agendados (nao vao publicar na hora errada)
- [ ] Verificar: newsletter pronta para enviar (subject line ok, preview ok)

## Go/No-Go Decision

**Producer faz decisao final:**
- [ ] Go: TUDO ok, publicar no horario agendado
- [ ] No-Go: algum issue critico → atrasar publicacao e corrigir

**Se Go:**
- [ ] Press "Publish" no hosting platform (RSS feed atualiza)
- [ ] Verificar: episodio apareceu em Apple Podcasts/Spotify (pode demorar 15-60min)
- [ ] Enviar newsletter
- [ ] Publicar posts sociais
- [ ] Notificar equipe: "Episodio S{XX}E{XX} is LIVE!"
- [ ] Monitorar primeiras 2 horas (comentarios, feedback, issues)
