# *cross-promotion

Identificar podcasts alinhados, propor ad swap ou feed drop, trackear resultados. Custo $0, ROI alto (10-50 novos subscribers por swap).

## Uso

```bash
# Identificar podcasts para swap
*cross-promotion --find-podcasts --niche "tech,ai" --audience-size "10k-50k"

# Propor ad swap
*cross-promotion --propose-swap --target "Podcast XYZ" --type ad-swap-30s

# Trackear resultados
*cross-promotion --track-results --partnership "Podcast ABC"
```

## Steps (Resumido)

1. **Identificar podcasts alinhados**
   - MatchMaker.fm
   - Podchaser
   - Criterios: Mesmo nicho, audiencia similar, valores aligned

2. **Propor ad swap**
   - Email template:
   ```
   Oi {Nome},

   Produzo o podcast {Nome} sobre {tema}.
   Adoro seu show e acho que nossas audiencias se sobrepoem.

   Toparia um ad swap? (30s em cada show)

   Abraco,
   {Nome}
   ```

3. **Negociar termos**
   - Duracao: 30s ou 60s
   - Insercao: Pre-roll, mid-roll, post-roll
   - Timeline: Lancamento simultaneo

4. **Criar promo scripts**
   ```
   [30s AD SWAP]
   "Se voce gosta de {tema}, vai amar {Nome Podcast}.
   Host {Nome} traz {value prop}.
   Busque {Nome Podcast} no seu app preferido."
   ```

5. **Tracking**
   - Promo code: "Use codigo XYZ"
   - UTM link: `podcast.com/?utm_source=swap&utm_campaign=xyz`

6. **Executar simultaneo**
   - Ambos lancam no mesmo dia

7. **Trackear resultados**
   - Downloads com promo code
   - Novos subscribers
   - ROI: Custo $0, gain 10-50 subs

8. **Follow-up**
   - Agradecer parceiro
   - Compartilhar resultados
   - Propor swap futuro

## Criterios de Qualidade

- [ ] 5+ podcasts contatados
- [ ] 2+ swaps fechados
- [ ] Promo scripts profissionais (30s, 60s)
- [ ] Tracking configurado (promo code)
- [ ] Lancamento simultaneo
- [ ] Resultados documentados
- [ ] ROI >10 subs por swap
