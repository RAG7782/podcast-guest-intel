# Workflow: Monetization Cycle

## Visao Geral
- **Objetivo:** Gerar receita sustentavel atraves de sponsorships, memberships e outras fontes
- **SLA Total:** Ciclo mensal continuo
- **Owner:** @monetizer

## Etapas

### Semana 1: Prospeccao de Sponsors
- **Owner:** @monetizer + @producer
- **SLA:** 7 dias
- **Entrada:** Audience demographics, download numbers, engagement metrics
- **Saida:** Shortlist de 10-15 sponsors potenciais
- **Checklist:**
  - [ ] Research de Sponsors:
    - [ ] Identificar marcas que fazem sentido para audiencia
    - [ ] Pesquisar budget de marketing (sao B2B? B2C? tech?)
    - [ ] Verificar se ja patrocinam outros podcasts
    - [ ] Avaliar fit de valores (usar @guardian para review)
  - [ ] Media Kit:
    - [ ] Atualizar metrics (downloads, demographics, engagement)
    - [ ] Incluir case studies de sponsors anteriores
    - [ ] Definir packages (episodio unico, temporada, year-long)
    - [ ] Pricing: CPM model ou flat fee
  - [ ] Outreach List:
    - [ ] Priorizar (A, B, C tier)
    - [ ] Identificar decision-maker (marketing director, brand manager)
    - [ ] Buscar warm intro (LinkedIn, network)
  - [ ] Outras Fontes de Receita:
    - [ ] Membership/Patreon: definir tiers e beneficios
    - [ ] V4V (Value for Value): implementar Podcasting 2.0
    - [ ] Affiliate links: identificar produtos/servicos relevantes
    - [ ] Events: planejar live show ou workshop
    - [ ] Courses: avaliar criar curso baseado no podcast
    - [ ] Merch: avaliar demanda (poll na audiencia)

### Semana 2: Negociacao & Contratos
- **Owner:** @monetizer
- **SLA:** 7 dias
- **Entrada:** Shortlist aprovada
- **Saida:** 1-3 sponsors fechados
- **Checklist:**
  - [ ] Outreach:
    - [ ] Email personalizado com media kit
    - [ ] Seguir com call de discovery (15-30min)
    - [ ] Apresentar packages e pricing
  - [ ] Negociacao:
    - [ ] Entender objetivos do sponsor (awareness, conversions?)
    - [ ] Propor package customizado
    - [ ] Negociar pricing (margem de 20%)
    - [ ] Definir deliverables (host-read ads, social posts, newsletter mention)
  - [ ] Compliance:
    - [ ] Validar fit de valores (@guardian review)
    - [ ] Garantir transparencia (disclosure obrigatorio)
    - [ ] Evitar conflito de interesse (nao promover competidores)
  - [ ] Contrato:
    - [ ] Enviar proposta formal (SOW)
    - [ ] Incluir: deliverables, timeline, pricing, payment terms
    - [ ] Clausulas: exclusivity, performance metrics, cancellation
    - [ ] Assinar e receber PO/pagamento inicial
  - [ ] Membership/V4V:
    - [ ] Configurar Patreon/Memberful (ou similar)
    - [ ] Definir 3 tiers (ex: $5, $15, $30/mes)
    - [ ] Beneficios por tier (ad-free, bonus episodes, Discord access)
    - [ ] Configurar V4V (Fountain, Breez, Alby)
    - [ ] Promover em episodios e social

### Semana 3: Producao de Ads
- **Owner:** @researcher + @host + @engineer
- **SLA:** 7 dias
- **Entrada:** Contrato assinado, brief do sponsor
- **Saida:** Ads produzidos e inseridos nos episodios
- **Checklist:**
  - [ ] Host-Read Script:
    - [ ] Receber talking points do sponsor
    - [ ] Escrever script natural (nao robotico)
    - [ ] Incluir CTA claro (URL, promo code)
    - [ ] Revisar com sponsor (1 round de feedback)
  - [ ] Gravacao:
    - [ ] Gravar ad em sessao dedicada (batch 4-8 ads)
    - [ ] Gravar 2-3 takes por ad
    - [ ] Tom natural e entusiasmado (nao forcar)
  - [ ] Edicao:
    - [ ] Editar ad (15-60s dependendo do package)
    - [ ] Masterizar para match o episodio
    - [ ] Exportar arquivo separado (para DAI)
  - [ ] Insercao:
    - [ ] Pre-roll (inicio): brand awareness
    - [ ] Mid-roll (meio): conversions (melhor posicao)
    - [ ] Post-roll (fim): CTA secundario
    - [ ] Dynamic Ad Insertion (DAI): configurar em hosting platform
  - [ ] Disclosure:
    - [ ] Mencionar no episodio: "Este episodio e patrocinado por..."
    - [ ] Incluir disclosure em show notes
    - [ ] Adicionar #ad em posts promocionais
  - [ ] Social/Newsletter:
    - [ ] Criar 1-2 posts mencionando sponsor
    - [ ] Incluir sponsor mention em newsletter
    - [ ] Tag sponsor em social (se acordado)

### Semana 4: Report & Renewal
- **Owner:** @monetizer + @analyst
- **SLA:** 7 dias
- **Entrada:** Ads rodando, analytics coletados
- **Saida:** Report enviado ao sponsor
- **Checklist:**
  - [ ] Performance Report:
    - [ ] Downloads/plays dos episodios com ads
    - [ ] Impressions (quantas vezes ad foi ouvido)
    - [ ] Completion rate (% que ouviu ate o final)
    - [ ] Click-through rate (se traceable)
    - [ ] Conversions (se promo code usado)
    - [ ] Social mentions (reach, engagement)
  - [ ] Enviar Report:
    - [ ] Email formal com metrics
    - [ ] Incluir: highlights, audience feedback
    - [ ] Propor: renewal ou upsell (ex: de 1 mes para 3 meses)
  - [ ] Renewal Outreach:
    - [ ] Follow-up 1 semana antes do fim do contrato
    - [ ] Oferecer discount para long-term deal
    - [ ] Ajustar package baseado em performance
  - [ ] Membership Report:
    - [ ] Total members por tier
    - [ ] MRR (Monthly Recurring Revenue)
    - [ ] Churn rate
    - [ ] New members vs. cancellations
    - [ ] V4V total (sats/boosts)
  - [ ] Internal Review:
    - [ ] ROI do sponsor (worth it?)
    - [ ] Fit com audiencia (feedback positivo?)
    - [ ] Renovar ou buscar novo sponsor?
    - [ ] Ajustar pricing para proximos deals

## Diagrama (Ciclo Mensal)

```
[Semana 1: Prospeccao]
   (Research + Media kit + Outreach list)
            |
            v
[Semana 2: Negociacao]
   (Discovery call + Proposta + Contrato)
            |
            v
[Semana 3: Producao de Ads]
   (Script + Gravacao + Insercao + Disclosure)
            |
            v
[Semana 4: Report + Renewal]
   (Performance metrics + Renewal outreach)
            |
            v
   [Repeat Monthly Cycle]
```

## Fontes de Receita (Paralelo)

```
[Sponsorships] (primaria)
      |
      +-- [Memberships/Patreon] (secundaria)
      |
      +-- [V4V (Podcasting 2.0)] (passiva)
      |
      +-- [Affiliate Links] (passiva)
      |
      +-- [Events/Workshops] (ocasional)
      |
      +-- [Courses] (evergreen)
      |
      +-- [Merch] (ocasional)
```

## Metricas de Sucesso
- **Revenue Goal:** R$ 5.000/mes (ano 1), R$ 15.000/mes (ano 2)
- **Sponsor Retention:** 60%+ renovam contrato
- **MRR Growth:** 10%+ ao mes (memberships)
- **CPM:** R$ 50-100 (media do setor: R$ 25-75)
- **Conversion Rate:** 2%+ usam promo code do sponsor
- **V4V:** R$ 500+/mes em boosts/donations

## Pontos de Falha Comuns
- **Sponsor Misalignment:** Promover produto que audiencia odeia → @guardian review ANTES de fechar
- **Overmonetization:** Ads demais → maximo 2 mid-rolls por episodio
- **Generic Ads:** Script robotico → host deve escrever com voz propria
- **No Tracking:** Sem promo code/UTM → sempre usar URL trackavel
- **Pricing Baixo:** Undervalue do podcast → pesquisar CPM do setor
- **Churn Alto:** Membership sem valor → delivery de beneficios todo mes
- **Late Reports:** Sponsor sem visibilidade → enviar report nos primeiros 5 dias do mes
