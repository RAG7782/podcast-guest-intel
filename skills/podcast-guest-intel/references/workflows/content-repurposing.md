# Workflow: Content Repurposing

## Visao Geral
- **Objetivo:** Maximizar alcance do episodio atraves de conteudo multi-canal
- **SLA Total:** 5 dias pos-publicacao
- **Owner:** @editor

## Etapas

### Dia 0: Episode Published
- **Owner:** @distributor
- **Entrada:** Episodio publicado em todas as plataformas
- **Saida:** Assets prontos para repurposing
- **Checklist:**
  - [ ] Audio master (WAV)
  - [ ] Video master (se aplicavel)
  - [ ] Transcript completo
  - [ ] Show notes publicadas
  - [ ] Timestamp de momentos destacados (5-10 clips)
  - [ ] Quotes visuais (3-5)
  - [ ] Artwork/thumbnail

### Dia 1: Social Clips & Audiograms
- **Owner:** @editor + @growth
- **SLA:** 1 dia
- **Entrada:** Audio/video master, timestamps
- **Saida:** 3-5 clips editados para social
- **Checklist:**
  - [ ] Selecionar 3-5 momentos mais virais/valiosos
  - [ ] Cortar clips: 30-60s para TikTok/Reels, 60-90s para YouTube Shorts
  - [ ] Adicionar legendas (auto + manual review)
  - [ ] Criar audiograms (waveform visual) para clips sem video
  - [ ] Adicionar hook visual nos primeiros 3s
  - [ ] Exportar em formato vertical (9:16) e quadrado (1:1)
  - [ ] Escrever copies por canal (templates abaixo)
  - [ ] Agendar posts: TikTok (18h), Reels (19h), Shorts (20h)

**Copy Templates:**
- TikTok: Hook curto + emoji + CTA ("Link na bio")
- Instagram Reels: Hook + contexto 2-3 linhas + hashtags + CTA
- YouTube Shorts: Hook + "Episodio completo no canal" + keywords
- Twitter/X: Quote do clip + link do episodio + thread (se relevante)
- LinkedIn: Contexto profissional + insight + link

### Dia 2: Newsletter & Blog Post
- **Owner:** @editor
- **SLA:** 1 dia
- **Entrada:** Transcript, show notes
- **Saida:** Newsletter enviada + blog post publicado
- **Checklist:**
  - [ ] Newsletter (Substack/Beehiiv):
    - [ ] Subject line com hook
    - [ ] Resumo do episodio (3-5 paragrafos)
    - [ ] 3 key takeaways
    - [ ] Quotes do guest (se aplicavel)
    - [ ] CTA para ouvir episodio completo
    - [ ] Preview do proximo episodio
    - [ ] Polls/perguntas para engajamento
  - [ ] Blog Post SEO:
    - [ ] Expandir show notes em artigo completo (2000+ palavras)
    - [ ] H1 com keyword principal
    - [ ] H2 por topico do episodio
    - [ ] Inserir timestamps clicaveis
    - [ ] Adicionar imagens/quotes visuais
    - [ ] Internal links para episodios relacionados
    - [ ] CTA para subscribe no podcast
    - [ ] Executar checklist seo-podcast.md

### Dia 3: LinkedIn Article & Twitter Thread
- **Owner:** @growth
- **SLA:** 1 dia
- **Entrada:** Blog post, key takeaways
- **Saida:** LinkedIn article + Twitter thread publicados
- **Checklist:**
  - [ ] LinkedIn Article:
    - [ ] Reescrever blog post com angulo profissional
    - [ ] Adicionar "lessons learned" para audiencia LinkedIn
    - [ ] Incluir CTA para network/comentarios
    - [ ] Mencionar guest (tag no LinkedIn)
    - [ ] Publicar e promover em Stories
  - [ ] Twitter Thread:
    - [ ] Tweet 1: Hook + contexto
    - [ ] Tweets 2-8: Key insights (1 por tweet)
    - [ ] Tweet final: CTA + link do episodio
    - [ ] Adicionar alt text em imagens
    - [ ] Agendar thread para horario de pico
    - [ ] Pin thread no perfil por 24h

### Dia 4: Community Discussion & Poll
- **Owner:** @growth
- **SLA:** 1 dia
- **Entrada:** Episodio + key themes
- **Saida:** Discussao ativa na comunidade
- **Checklist:**
  - [ ] Discord/Slack:
    - [ ] Postar resumo + link no canal #episodios
    - [ ] Iniciar thread de discussao com pergunta provocativa
    - [ ] Postar poll relacionado ao tema
    - [ ] Responder comentarios (primeiras 2h criticas)
  - [ ] Outros canais (Reddit, Facebook Group):
    - [ ] Postar com contexto relevante para cada comunidade
    - [ ] Adaptar linguagem ao tom da comunidade
    - [ ] Evitar spam (regra: contribuir ANTES de promover)
  - [ ] Listener Poll:
    - [ ] Criar poll no Spotify/Apple (se disponivel)
    - [ ] Ou usar Instagram Stories/Twitter
    - [ ] Pergunta: "O que achou?" ou tema especifico do episodio
    - [ ] Usar resultados para planejar futuros episodios

### Dia 5: Behind the Scenes & Postmortem
- **Owner:** @editor + @producer
- **SLA:** 1 dia
- **Entrada:** Materiais BTS, analytics iniciais
- **Saida:** BTS post + internal postmortem
- **Checklist:**
  - [ ] Behind the Scenes:
    - [ ] Foto/video dos bastidores
    - [ ] Story no Instagram: prep, gravacao, fun moments
    - [ ] Post no Patreon/membership (exclusive content)
    - [ ] "Making of" curto (1-2min) para YouTube
  - [ ] Episode Postmortem (interno):
    - [ ] Analytics primeiros 5 dias (plays, completion rate)
    - [ ] Engagement em social (likes, shares, comments)
    - [ ] Feedback da audiencia (comentarios, DMs, emails)
    - [ ] O que funcionou bem?
    - [ ] O que pode melhorar?
    - [ ] Aplicar learnings no proximo episodio
  - [ ] Thank You:
    - [ ] Enviar analytics para guest (se aplicavel)
    - [ ] Agradecer equipe (Slack/Discord)

## Diagrama

```
[Dia 0: Episode Published]
          |
          v
[Dia 1: Social Clips + Audiograms]
    (TikTok, Reels, Shorts)
          |
          v
[Dia 2: Newsletter + Blog Post]
    (Email list + SEO page)
          |
          v
[Dia 3: LinkedIn + Twitter Thread]
    (Professional + microblogging)
          |
          v
[Dia 4: Community + Poll]
    (Discord, Reddit, Listener poll)
          |
          v
[Dia 5: BTS + Postmortem]
    (Behind the scenes + analytics)
          |
          v
[Cycle Complete]
```

## Metricas de Sucesso
- **Reach Multiplier:** 3x+ o alcance do episodio atraves de repurposing
- **Engagement Rate:** 5%+ em posts sociais
- **Newsletter Open Rate:** 40%+ (media do setor: 20-30%)
- **Blog Post Traffic:** 500+ visits nos primeiros 30 dias
- **Community Engagement:** 20+ comentarios/respostas no Discord/Reddit
- **Completion Rate:** 70%+ dos viewers assistem clips ate o final

## Pontos de Falha Comuns
- **Clips Nao Convertem:** Hook ruim → testar primeiros 3s em A/B test
- **Newsletter Ignored:** Subject line fraco → usar curiosity gap ou benefit-driven
- **Blog Post Nao Ranqueia:** SEO mal feito → executar checklist seo-podcast.md rigorosamente
- **Zero Engagement em Community:** Post muito promocional → fazer 3 contribuicoes ANTES de promover
- **BTS Nao Interessante:** Conteudo generico → mostrar moments "humanizados" (erros, risadas, prep)
- **Burnout:** Muito conteudo para criar → batch production (gravar 3-4 episodes, depois repurposar todos)
